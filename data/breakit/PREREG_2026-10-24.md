# Break-it test for the readability bound. Pre-registered 2026-10-24, before any run.

Question: does Gamma_self >= gamma * max(2 kappa^2, eps_KL^2 / 2) survive outside
the hypotheses it is proven under? If it fails, "a fundamental limit on peeking"
is dead in its current form; if it holds, that is evidence for generality, not
proof. Written before the script exists; nothing below is changed after a result.

## Machinery (reused, not rebuilt)

code_release/ v1.3: perception_frontier.cat_code(sqrt(1.9), 2) and
gkp_code(2, 80), each with its own dissipative stabilizer (code["stab"]);
Gamma_self = the windowed log-derivative of the logical-Z autocorrelation under
the full Liouvillian, autocorr_rates_fixed + stable() from
autocorr_extract_d3fix.py, exactly as for Table II. Read operator: cat
logops[2], GKP logops[1] (as table2()). Read-basis codewords: code["z_states"],
orthonormalized.

## Harness check (must pass or the test stops)

The twelve Hermitian Table II cells at gamma = 0.05 must reproduce the printed
values within 15% (table2()'s own expectation is ten within 6%, GKP-p 1.06x,
GKP-n 1.13x).

## Arm A: non-Hermitian meters (outside "Hermitian meters")

Lindblad meter c_op = sqrt(gamma) L, gamma = 0.05, L in:
- `a`  (photon loss / heterodyne-type record),
- `a2` = a^2,
- `E`  = sum_n |n><n+1| (Susskind-Glogower exponential phase; the closest
  continuous-measurement analogue of a phase readout),
- `E2` = E^2.
Two codes x four meters = 8 cells.

Generalized quantities, fixed now (both reduce to the paper's for Hermitian L):
- kappa_g^2 = (|<0|L|1>|^2 + |<1|L|0>|^2) / 2  (the exact within-code flip rate of
  D[P L P] on Z is gamma (|L01|^2 + |L10|^2) = 2 gamma kappa_g^2);
- E|mu> = P_perp L |mu>, Lambda = E^dag E, eps_KL^2 = |Lambda_01|^2 / Tr Lambda;
- bound_g = gamma * max(2 kappa_g^2, eps_KL^2 / 2).

## Arm B: strong measurement (outside "leading order in gamma/g")

The twelve Hermitian Table II cells at gamma in {0.2, 0.8, 3.2} (4x, 16x, 64x the
paper's 0.05). The bound uses each cell's kappa and eps_KL (gamma-independent),
so it grows linearly in gamma. A Zeno-type suppression of the leak would show as
Gamma_self falling below it.

## What counts as a violation

A cell VIOLATES when all hold: the windowed estimator is stable (no UNSTABLE
flag), the bound exceeds 1e-6 (below that it is numerical noise), and
Gamma_self < 0.8 x bound (a 20% margin, above the 13% estimator deviation seen
in Table II). Unstable cells and cells with bound <= 1e-6 are reported, not
judged.

## What each outcome means (decided now)

- Arm A, no violation in 8 cells: the natural extension survives on these meters.
  Evidence, not proof; a proof for general L is still needed.
- Arm A, any violation: the floor as written does not extend to non-Hermitian
  continuous meters. The "fundamental limit" framing is false for the current
  form; report which term (kappa or eps_KL) failed and at which cell.
- Arm B, violation: the bound is a weak-measurement statement only; report the
  smallest gamma where it first fails, per cell. This does not contradict the
  theorem (proven at leading order) but limits any "peek" claim to weak peeks.
- Arm B, no violation: the bound survives 64x beyond the paper's operating point
  on these cells.

## Not tested here (stated so it is not mistaken for coverage)

- Number-phase codes read by the canonical phase POVM, the paper's named open
  question: the code base has no dissipative stabilizer for number-phase codes,
  and building one is new physics needing its own pre-registration.
- Adaptive measurement (feedback during readout), discrete syndrome rounds,
  d > 2, multimode codes.
